# 小型交通标志含义识别：资料盘点与实施计划（2026-09-26）

## 结论与依据

可以把小标志识别扩展成「在道路原图中定位标志 → 识别具体图案和可变数字/文字 → 查询有来源的含义 → 给出图像证据或拒答」。当前四类 YOLO 只能把 0/1/3 分成警告、禁令、指示，不能直接识别具体含义；RAG 检索只能解释**已经识别并核实的细类**，不能替代图像分类。

优先依据：

- 国家标准公开平台：[GB 5768.2-2022《道路交通标志和标线 第2部分：道路交通标志》](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=15B1FC09EE1AE92F1A9EC97BA3C9E451&refer=outter)，页面标为现行，并标注第 1 号修改单。入库时应核对修改单与具体条目，不能把网站图解直接称为标准原文。
- 北京市公安局交通管理局：[图解交通标志线](https://jtgl.beijing.gov.cn/jgj/lszt/659722/10860935/)提供逐项图案、名称和释义。2026-09-26 按页面结构盘点到禁令 48 图示、指示 43 图示、警告 72 图示；警告有同名图案变体，共 56 个不同名称。此为**网页图示数量**，不是国标的法定条目总数，也不是本数据集覆盖的细类数。
- 深圳交警的[标志类别说明](https://szjj.sz.gov.cn/YWZSK/JSYZS/content/post_10094451.html)用于核对三类的功能边界：警告是提示注意，禁令是禁止/限制，指示是要求遵循。辅助牌会改变时间、车辆、方向、距离等适用范围，不能只看主牌。

`knowledge/small_sign_source_index.json` 保存上述北京交管页面的 163 个图示索引（名称、类别、原图链接、网页来源），其中 22 个不同名称附有项目转述的初步释义，其余保留空值，作为待复核候选目录。未复制官方图像或整段释义；目录条目不代表本项目已经会识别它们。现有 `knowledge/signs.yaml` 仍只表示项目的四个检测大类，且按内部标注规范定义，不应被国标细类目录直接覆盖。

## 数据现实与标注

只读扫描现有 YOLO 标注：`D:\Private-dataset-master\labels` 有 10,230 个标注文件，0/1/3 类检测框分别为 3,269 / 7,463 / 5,144；`D:\images-night\from hainan\imagesnight` 的 train/val 共 3,912 个标注文件，对应为 801 / 4,173 / 3,665。数字是**大类检测框数**，并非独立标志实体数、可读细类数或独立训练样本数，两数据集也可能有重复场景。

1. 用原始标注框裁出 0/1/3 类标志，保存来源路径、批次、原图坐标与框尺寸。原数据按批次可能有重名文件；索引键必须含数据源和批次。先统计裁剪分辨率、遮挡、夜间炫光、可见辅助牌比例。
2. 对裁剪图去重并聚类，人工查看每簇：选取网页目录中的精确细类，或标 `other_standard`、`nonstandard`、`unreadable`、`ambiguous`。同一块牌在连续帧中只算一个物理实体。记录主牌、辅助牌及其关联；限速、限高等数值另设结构化字段。
3. 先做数据中真实出现且样本足够的高频细类，而不是把 147 个目录名称全部设为训练类别。按实体/拍摄序列/数据源切分开发集与冻结测试集；人工双人复核易混项和负样本。未在原数据出现的官方标志只留在目录中，不宣称模型覆盖。

## 分阶段开发和验收

1. **阶段 A：目录与标注审计。** 把来源目录补成机器可读知识项：稳定 ID、官方名称、项目转述含义、标准版本和条目定位、视觉辨别要点、可变字段、辅助牌影响、易混类、适用地区/来源、复核状态。先完成 20 个数据中确实出现的细类；经人工核对后才允许用于回答。输出细类频次、可读率、重复率、误标样本报告。
2. **阶段 B：视觉细分类。** 保留现有 YOLO 做原图定位；对检测框的原图高清裁剪训练或比较轻量细分类模型（也可先用图像检索做基线）。必须加入 `unknown` 和低质拒答。对数值型标志并行做 OCR/数字识别；不能把示例图片上的数字写死在知识库。
3. **阶段 C：证据绑定的知识回答。** 模型输出 `bbox`、细类 ID、数值及置信度；以细类 ID 精确检索已审核知识项，再生成简短解释与官方来源链接。辅助牌单独检测/识别并连接主牌；看不清就注明作用范围未知，不猜时间、距离或车辆类型。RAG 可以解释已确认结果，不让生成模型自行决定牌型。
4. **阶段 D：冻结评测与页面展示。** 从道路原图开始评测检测召回、细类 macro-F1/混淆矩阵、数值 exact match、端到端含义正确率、按置信度分层的覆盖率和错误率，以及未知/模糊牌的拒答效果。测试集需同时有日/夜、模糊/小目标、易混类、非标准标志和辅助牌。页面展示原图框、牌面放大图、解析字段、知识来源与拒答原因。

**第一阶段可交付目标（待数据审计后调整）：** 从真实样本中选至少 12 个高频细类；每类至少 20 块不同实体牌，冻结测试合计不少于 200 块，其中至少 40 块为未知、低质或易混负样本；以原图输入衡量细类 macro-F1、含义准确率和拒答误报率。数值牌的数值识别单独报告。门槛是项目目标而非现有成绩；若某些类达不到样本量，缩小范围并报告覆盖边界。

## 关键局限

- 官方目录不能直接变成图像训练标签；现有大类框不含细类名。网页图示主要是规范图形，直接拿其图像做模板容易与真实夜间、斜视、小目标照片产生域差。
- 北京交管图解是一份便利的图示目录，国标本体及第 1 号修改单仍须逐项校核。复用时存项目转述、链接和版本，不批量复制官方图片或原文到公开仓库。
- 主牌含义受辅助牌限制；检测不到辅助牌时只应输出无附加限定的基础含义，并明确范围未知。含义识别是图像理解演示，不应被呈现为行车指令或法规判定。
