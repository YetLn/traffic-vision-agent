# 粗类检测微调与倾斜箭头实验（2026-10-04）

本轮只使用已有 0–3 类检测标注；没有补造细牌型、数值或辅助牌标签。小标志知识库和含义范围未改动。实验产物在本机忽略版本控制的 `outputs/` 中，应用仍使用 `weights/traffic_best.pt`。

## 数据与隔离

`scripts/build_finetune_split.py` 从白天、海南夜间两个数据集抽取 553 张训练图、76 张验证图，沿用原始检测框。训练集含白天 433 张、夜间 120 张；验证集含白天 50 张、夜间 26 张。白天以文件编号的百位块暂代采集实体，夜间使用原清单中的 `group_id`；实际选中白天训练/验证块 64/35 个、夜间训练/验证组 19/3 个，两个分区均无组交叉。35 张方向开发图及其白天编号块或夜间采集组不进入本次训练。还用 SHA-256 和 pHash 筛去训练与验证/方向开发图的相同或高度相似图。

这些分组只能降低泄漏，不能证明不同编号块是不同实体。验证集内部另有一对相似场景（`09745.jpg`、`09216.jpg`），所以它不是独立核验过的冻结测试集。原应用权重的历史训练清单也不能据此反推，以下比较仅作开发实验。

`08581.jpg` 的原始 2 类标签把相邻的多块步行方向条牌合成较大的框，缺少逐条牌面框。微调可以学习发现这个区域，却无法从这些框学到准确的单条定位。

## 检测实验

从现有 YOLOv12n 权重出发，使用 512 像素、batch 1、AdamW 学习率 0.0002 训练 4 轮；关闭 mosaic、mixup 和 AMP。AMP 自检会尝试获取本项目不需要的 `yolov13n.pt`，本机因 GitHub 403 无法完成，因此正式训练显式关闭 AMP。训练结果保存于 `outputs/finetune_direction_20261004_v2/runs/b1_512_e4_noamp/weights/best.pt`，未覆盖应用权重。

两权重都以 640 像素、置信度 0.25 在同一 76 张分组留出原图上评估；IoU≥0.5 算粗类 2 框命中。“宽牌”按**像素框**宽高比≥2 划分，只有 10 个标注框。

| 指标 | 应用权重 | 微调权重 |
|---|---:|---:|
| 2 类框召回 | 34/62 | 49/62 |
| 宽牌框召回 | 4/10 | 9/10 |
| 含 2 类图中至少命中一框 | 27/41 | 34/41 |
| 2 类预测框总数 | 59 | 124 |
| 未匹配粗标注的 2 类预测框 | 25 | 75 |

未匹配框不能直接当作假阳性：原粗标注可能漏框。但预测量翻倍，须由完整牌面核验或下游回归判断是否值得启用。在 `08581.jpg`，应用权重未找到 2 类牌面；微调权重提出 3 个互相重叠的粗框，方向关系仍为 0。

## 原图方向回归与箭头实验

35 张已有方向开发图均从道路原图进入 YOLO，没有替换人工检测框。候选权重保持默认保守箭头解析时，结果如下：

| 指标 | 应用权重 | 微调权重 |
|---|---:|---:|
| 预测牌面数 | 36 | 67 |
| 匹配金标牌面 | 25/35 | 31/35 |
| 正确方向关系 | 9/31 | 6/31 |
| 26 块负牌错误输出方向 | 0 | 0 |

微调权重虽多找到牌面，但在原先能输出 3 条关系的 `day-40268f489a-0e00e403` 上退化为 0 条。该权重未满足端到端收益要求，因此不部署。拒答仍守住当前 26 块负牌，但它们也是开发集，不能外推到未知负牌。

另做独立的“倾斜箭杆”形状模板实验，保持图形 IoU 阈值 0.82 与方向差阈值 0.16 不变。使用应用权重在同一 35 张图上，关系仍为 9/31，负牌错误仍为 0。唯一新增箭头证据来自 `08485.jpg`：上半区直行箭头与下半区右前方箭头都被分类为 `up`，虽然关联层因歧义未输出关系，这个内部误分类仍不宜启用。代码仅通过 `--experimental-shear` 显式开关复现，默认解析继续使用原模板。

## 下一步判断

检测器的粗类召回瓶颈已有改善，但现有合并框无法训练逐条步行牌定位；检测后多框裁剪也可能让原本正确的关联失效。下一轮应先针对**已提出的重叠牌面**设计去重/完整牌面选择，并在当前 35 张开发图和分组留出图上同时检查召回、正牌关系和负牌拒答。若要给出独立的细牌型准确率或安全扩大小标志含义，仍需与开发图隔离、逐实例核验的细粒度数据。
