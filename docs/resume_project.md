## 一、主文案（可直接粘贴，通用版）

**交通场景视觉 AI Agent｜独立开发**　2026.06 – 至今

针对夜间交通标志检测模型只能输出检测框、缺乏自然语言交互能力的问题，将已有昼夜训练 YOLOv12 权重封装为可调用视觉算子，构建基于 Tool Calling 的查询 Agent，支持上传图片后用自然语言完成检测、计数、画框与标志含义查询。

- **视觉算子层**：基于 Python 与 Ultralytics 将检测权重封装为统一结构化接口，拆分 `detect` / `count` / `highest_confidence` / `visualize` 四个工具，输出类别、置信度与边框 JSON，并统一处理 EXIF 方向、超大图校验与共享模型串行推理。
- **会话与上下文管理**：用「图像内容哈希 + 检测阈值」作会话内检测缓存键，同会话重复问答复用推理、换图或调阈值即失效，避免重复推理；用结构化折叠替代窗口截断管理多轮历史，把较早轮次压缩为类别统计、关注类别与轮次计数，历史恒定保留最近 6 条消息，上下文体积不随轮数增长。
- **工具调用 Agent 调度层**：接入 DeepSeek Function Calling，由模型按自然语言问题自主选择工具；工具名 / 参数 / 类别名白名单校验，单轮工具调用不超过 4 轮、每轮不超过 4 次，超时 45 秒，调用失败以结构化错误回传模型而非中断；保留一套确定性关键词路由作为无密钥离线基线。
- **语义知识库**：实现本地标志语义检索工具 `lookup_sign`（YAML + 关键词/别名匹配，无向量库依赖）；含义与依据为空的类别一律返回 `available=false`，要求模型明确拒答，杜绝按外观臆测；依据如实标注为项目自有标注说明（团队内部依据，非国标）。
- **评测与验证**：20 项 unittest 覆盖缓存与指代、换图/阈值失效、空检测、工具参数校验、工具循环上限、会话隔离、上下文折叠边界与摘要注入；3 张真实夜间样例完成真实权重推理，单张检出 2 个目标、最高置信度 0.9130，CPU 单次检测 305–2057 ms；用真实 API 完成 8 轮多轮联调与真实图片语义问答端到端验证。

技术栈：`Python` · `YOLOv12 (Ultralytics)` · `DeepSeek Function Calling` · `Gradio` · `Conversation Context Folding` · `Local Knowledge Retrieval` · `unittest` · `Git`

> 核心代码约 635 行有效代码（744 行含注释与文档字符串），另有 5 个可复现验收脚本。

## 二、能力边界（面试被追问时用，建议自己心里有数，不写进简历）

- 置信度数值只是那 3 张样例的单次结果，**不是准确率或延迟基准**，不能声称整体精度或泛化能力。
- 模型只有 4 个粗粒度类别（wran / ban / point-l / point-s），**不支持限速值识别、OCR、遮挡分析与安全决策**；检测结果不能用于行车安全判断。
- 语义知识库是**关键词/别名检索**，不是向量检索；类别含义来自团队内部标注说明，非国标。
- 上下文折叠是**确定性结构化压缩**（自己算统计），不是 LLM 生成摘要。
- 未实现：RAG、向量库、LangChain、多模型路由、自进化、多 Agent。

## 四、面试可能追问与可用回答

| 追问 | 回答要点 |
| --- | --- |
| 上下文压缩和 ReAct 的 Memory 有什么区别？ | ReAct 是“思考-行动-观察”循环范式，我这里实现的是工具调用循环；上下文折叠解决的是多轮历史过长的工程问题，用确定性统计压缩，避免策略模型在压缩阶段改写检测事实。 |
| 为什么不直接让模型记住检测结果？ | 检测结果明细不进对话历史，只进会话缓存与折叠统计，避免模型把历史里的数字当成新的事实；问图片事实必须重新调用工具。 |
| YOLO 权重哪来的？ | 本人此前交通标志检测研究中训练的昼夜权重。本项目重点不是重新优化 mAP，而是探索视觉模型与 LLM 工具调用的集成；因此按工程解耦原则复制权重进项目，训练代码不修改。 |
| 用了 LangChain 吗？ | 没有。调度层是自己写的显式工具循环，便于精确控制轮数、参数白名单与失败回传；也因此不引入框架版本风险。 |
| 效果如何？ | 只给可复现的数字：20 项测试通过、3 张夜间样例各检出 2 个目标、真实 API 8 轮联调与语义问答端到端通过；这些都是单次验收结果，不是基准测试。 |
| 标志含义的依据是什么？ | 团队内部的标注说明文档，不是国标；知识库把依据来源一起返回，没有依据的类别直接拒答。 |
